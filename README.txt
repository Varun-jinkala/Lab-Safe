Virtual Science Laboratory
==========================
Run: open index.html in a modern desktop browser (Chrome, Edge, Firefox, Safari).
Needs internet once for Three.js r128 from cdnjs.cloudflare.com
(https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js).
To work offline, download that file next to index.html and change the <script src> to "three.min.js".

Contents: 21 experiments (7 Chemistry, 7 Physics, 7 Biology), live graphs, observation log,
Web Audio sounds, graded quizzes. Single file, no build step, no server needed.

Status: written but NOT tested in a browser. Not implemented: drag-and-drop of apparatus,
camera pan, PNG export, file-download CSV (copy only), cinematic intro, ambient animation.
Educational simulation with simplified models; not a substitute for supervised lab work.
